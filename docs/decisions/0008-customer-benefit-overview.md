# ADR-0008 客户权益分析与时点统计

- 状态：已接受（原型及统计口径，正式后端待实现）
- 日期：2026-09-09；关联REQ-029、TASK-039～041。

平台和资源方各自提供客户权益概览，不合并角色数据。以开卡批次集合为固定观察对象，用事件发生时间重建每一期末状态；预约率和核销率按客户去重，激活率按卡片。周/月重算集合，不平均日比率。取消或核销撤销不抹去此前历史。

复用现有React/Arco的筛选、指标卡、表格、Drawer和Excel工具；轻量趋势使用原生SVG与Arco色彩变量，不新增图表依赖或构建链。SVG仅为数据图形，不仿制基础控件，提供坐标、点值、空点及等价表格。正式复杂分析需求再评估图表库。

备选方案：直接按当前记录状态反推历史更简单，但会把取消前预约也抹掉；按当月激活/当月采购会错配批次。采用事件投影需要保存完整时点，这是正确解释趋势的必要代价。

原型使用明确标记的分析样例，并只读投影当前角色已审核销售卡。既有缺日期记录不臆造历史；原客户列表保留只读历史。新概览页不建立发放/支付能力，也不改变原账单状态。缓存升级前备份，原型回退须保留新增缓存与旧记录。

服务端未来需要按机构授权查询、全局客户ID、幂等事件、统一时区、数据覆盖与更新时间、审计和可复算聚合。原型的筛选并不是生产访问控制，跨角色与小程序数据仍不互通。
