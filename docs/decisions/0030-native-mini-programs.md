# ADR-0030 两个原生微信小程序及无账号阶段验证

2026-09-13；REQ-047 / TASK-097～100。采用微信原生WXML/WXSS/TypeScript，两份AppID、原生App/Page及独立会话；共享基础源码在构建时复制到各自包内，不引入跨平台框架或WebView。既有Django业务规则不复制到客户端。

继承Arco品牌色、状态语义及移动设计，原生控件承担手机号授权、日期时间、扫码、地图和付款。不打包后台React/Arco库。TypeScript类型采用微信维护的[api-typings](https://github.com/wechat-miniprogram/api-typings)；二维码使用MIT [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)离线编码服务端返回的不透明凭证，不向第三方发送凭证。

无账号阶段生成可审查的源码包，AppID使用touristappid；正式登录须检查真实配置。不接受客户端自报手机号/OpenID、不增加后端测试登录入口。控制器测试用wx替身，后端契约测试仅在隔离库模拟微信提供方。测试替身、私钥、后台Basic口令不进包。API地址默认空，显式注入批准的HTTPS来源，缺配置明确提示，不回退模拟。

支付由服务端查单确认；微信回调成功不直接改账单。写请求同内容重试保留幂等键，版本冲突要求刷新；核销先报价、确认治疗完成，再提交。二维码不进URL、日志或本地持久存储；会话仅内存，页面隐藏清除敏感展示，返回重读。拒绝定位仍可搜索。

账号未申请，微信登录/手机号、原生WXML编译、地图/相机/隐私弹窗/支付、体验版发布尚不能验收。所有可执行测试仅在140.143.125.233；未授权本地微信开发者工具/真机例外。正式接入需独立API访问保护，禁止把后台Basic口令打包进小程序。主体、类目、隐私条款与手机号资格在账号配置时复核。
