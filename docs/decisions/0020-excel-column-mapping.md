# ADR-0020 机构Excel列映射与人工确认

- 状态：已接受；2026-09-09；REQ-041、TASK-073～075。

## 决定与取舍

采用确定性的列名别名识别、内容候选提示、人工确认和机构格式复用，不接外部AI，不要求所有机构重做标准模板。原型复用原无依赖.xlsx压缩/XML读取方式，抽出独立`shared/excel-import.js`，只由平台/资源方销售入口加载；UI复用Arco现有Drawer、Select、InputNumber、Checkbox、Alert和状态列表，不引入组件依赖。原三步销售向导不变，第二步容纳导入配置与预览。

识别结果不是业务确认。每次影响明细的修改撤销确认，后续提交再次检查已确认配置和所有明细。格式保存按机构命名空间，不保存客户样例；业务订单保存本次映射快照，未来模板修改不追溯订单。原型仅浏览器虚构数据；正式版应使用机构ID、服务端存储/鉴权、文件摘要和不可变导入版本，不把localStorage投影当安全实现。

解析器只支持受限平面表，工作簿关系用于选择真实工作表名/路径；宏/外链/公式保守拒绝，限制压缩及展开大小、条目、行列数量。原型不声称完整Office兼容或安全扫描。正式实现另行选择维护中的解析库并在隔离任务中限制资源，当前不为原型扩充完整办公文档引擎。

## 后果及验证

无需迁移已有订单；新订单附加导入快照，旧订单显示“历史未记录”，不补造。缺数量可显式统一填写，但模板不保存数值以避免下批误用。旧单客/实体卡和审核流程保持，旧解析函数保留严格自动映射兼容入口，但UI必须人工确认。验证包括文件及映射异常、数量守恒、复用隔离、订单冻结、销售回归；全部在指定服务器执行。失败快照保留，可回退上一提交和其演示存储；不回写正式业务数据。
