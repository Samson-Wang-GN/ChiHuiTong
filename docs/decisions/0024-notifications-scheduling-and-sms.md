# ADR-0024 通知、调度与短信适配

状态：实施中。关联TASK-084/085/086。

选择数据库发件箱与独立分钟级工作进程，避免借用共享Redis或新增复杂队列。每项任务有去重标识、租约、重试次数、错误码，失败可由平台复核后重试；不因发送失败撤销已提交预约或账单。

站内通知是消息，预约确认/改期、过期预约、审核和结算是业务待办；读过消息不视为处理业务。合作方结算每日只提醒相应管理员，不新增短信。门诊账单付款期内每日一次、首次发现逾期后一次短信；不自动上下线。

短信采用腾讯云固定HTTPS接口和TC3签名，配置凭据与业务模板分离。模板种类预置、平台只能配置受控变量、签名及服务商已报备ID。保留发送记录，状态“accepted”只表示服务商接受；真实运营商送达率仍需商户账户联调。超时可能发生服务商已发送但本地未知，有限重试不承诺外部严格一次送达，不输出完整手机号或响应。

依据：[腾讯云发送短信](https://cloud.tencent.com/document/product/382/55981)、[版本差异](https://cloud.tencent.com/document/product/382/68705)、[TC3签名规则](https://cloud.tencent.com/document/product/1278/46716)（2026-09-12查阅）。真实账号和模板未提供，远程仅使用合成网关/报文，不发送真实短信。
