# ADR-0001 Arco Design 与独立角色后台原型

- 状态：已接受（用户指定 Arco 与角色分组；原型实现方式为工程选择）
- 日期：2026-09-07
- 关联：REQ-019、TASK-019、TASK-020

## 背景

用户要求先完成四个机构角色后台原型，各组独立，原型和正式前端严格采用 Arco Design。当前仅有业务文档，无应用技术栈、Node/npm环境或Git仓库。

## 决定

在 `prototypes/platform`、`resource`、`channel`、`clinic` 创建独立页面入口和业务配置；只共享基础渲染代码和组件。采用本地固定发布包 React 18.3.1、ReactDOM 18.3.1、Arco React 2.66.16，以浏览器运行，无打包环境。离线依赖存放 `prototypes/shared/vendor`，不调用远程业务接口。正式Web保持Arco官方组件体系，后端架构及工程化选型另定。

## 备选与取舍

手写仿Arco样式容易偏离组件交互；在线CDN运行受网络影响；立即搭建完整生产应用超出本轮范围。本地官方发布包可精确复用组件并直接预览，代价是文件体积较大、页面配置集中于各角色文件。后续可逐页迁移为工程化React组件，迁移时保持业务交互和设计规范。

## 边界

样例数据在每个角色独立localStorage命名空间持久化，互不传播。仅供页面评审，不实现跨机构业务事务或真实登录；不得输入真实患者信息。来源展示名、金额、状态均以需求基线为准。原型不自动批准MVP冻结或详细岗位权限。

## 验证

检查独立入口、全部路由、浏览器错误、表单阻断、取消/回滚保护、筛选和详情；用桌面截图验证视觉。规范与验收记录见 `docs/design-requirements.md`、`docs/prototype-review.md`。
