# ADR-0035 合同收款配置、日期和大陆行政区

状态：实现和验证中。关联 REQ-054、TASK-113。

平台通过独立受限入口维护收款主体、收款说明、含税和开票安排；配置采用加密版本记录，新生成合同仅在模板引用新字段时使用，生成快照冻结字段值和当版生成日期，保留实际收签记录。此配置不修改微信商户或实际支付账户。旧模板和旧合同快照保持兼容；不以合同配置代表真实资金链和开票能力已验收。

新合同期限以起始自然日和1至30整数年计算，上海时区有效到截止日23:59:59.999999；2月29日目标非闰年时止于2月28日。旧合同和旧草稿沿用原时间字段。年限上限30是技术默认，待业务验收。服务端重新计算，不信任客户端提供的截止时间。

行政区使用已记录来源和CC0的2025县级以上参考数据，过滤港澳台；直辖及省直辖县级使用省名作为中间选择，无县级区划的地级市重复市名作为最后一级，避免虚构行政区名称。数据会滞后，需要按来源版本更新；老地址不批量改写。营业时间只允许同日有效起止，旧草稿原格式不强制转换。
