# ADR-0027 受保护的后端验收环境

2026-09-12，REQ-044。用户明确批准独立受保护HTTPS验收入口。

采用现有开发域名下独立 `/chihuitong/` 路径，复用现有TLS证书，仅增加该路径的Nginx配置引用；不改变既有路由、不开放新公网端口。应用只监听127.0.0.1:18243，独立验收库、附件、密钥和systemd服务。Nginx Basic访问口令与业务Bearer会话分开：验收客户端用X-CHT-Authorization承载业务会话，由专属代理转换；正式API认证协议不变。

验收模式需要显式开关、非生产环境、独立数据库名前缀及私有代理令牌。应用逐请求校验由Nginx覆盖写入的令牌，防止绕过入口保护。测试短信只写加密私有文件、只允许四个合成手机号；受保护短信箱检查当前验证码摘要、有效期、消费状态，禁止显示历史失效验证码。不改正式验证码返回结构，不设置通用验证码，不将验证码写日志。

提供使用既有React/Arco发布包的轻量后端验收台：四角色独立入口、真实登录和按服务端范围查询，允许技术人员在受限本地API路径上提交JSON验收请求。不是完整业务前端的替代品，持续显示该边界。完整前端对接另行实施，小程序不改。

合成种子使用正常领域服务生成合同、卡、权益、预约和账单；合成时间用于展示历史月结，不复制真实数据。初始化仅允许空验收库，完整事务及标记防重，重复调用不重置。真实支付关闭、短信无外发；原型不部署为已接通页面。

风险：验收口令持有人可以查看这四个演示账号的短信，因此是验收入口权限，不是手机号真实性认证。只允许纯合成资料，不能对生产开放。共享Nginx的修改先备份、语法检查再平滑重载，独立文件可移除回退；不停止既有服务。生产仍需非作者安全评审和真实第三方验收。
