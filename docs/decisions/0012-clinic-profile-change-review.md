# ADR-0012 门诊生效资料与变更审核分离

- 日期：2026-09-09
- 状态：已接受（原型；服务端待实施）
- 关联：REQ-033、TASK-055～056；替代ADR-0011中的普通资料直接生效和核心资料覆盖后重审规则，其地图方案保留。

采用单独变更申请快照，不把门诊主记录作为待审核工作副本。申请冻结原版、新版和基准版本；拒绝只修改申请，批准通过版本校验后原子替换资料白名单。资质结论、服务状态、合同、费用、员工认证和平台时限均不由申请字段控制。预约及合同历史快照不回写。

同门诊仅一个未决申请，提交前权限/字段及差异校验，审核有角色、申请状态、版本和材料校验；拒绝重提使用新申请编号。真实后端需行锁或乐观锁、唯一未决约束、事务、幂等、不可变附件和审计，不以浏览器校验代替。待确认时限独立平台配置，申请批准不得覆盖期间平台调过的时限。

原型复用Arco状态Tab列表、详情抽屉、差异表和现有附件组件；两方提交与平台任务审核分别在独立角色存储演示，平台固定样例不是跨端同步。旧缓存如缺少可靠的已审核版本，不能通过猜测历史还原；保留备份供人工核实。

验收覆盖任意资料变更不直接生效、拒绝保留、整版批准、重提、时限保护、越权/重复/基准版本冲突与全部附件可见；完整生产权限与事务仍需后续验证。
