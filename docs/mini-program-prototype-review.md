## 0.23试用路径

1. 客户登录后首页有OD72、ODABS两条“预约结果待处理”消息，显示门诊/时间/产品和权益占用。打开OD72可选择“未到诊，申请恢复权益”或“已到诊，完成治疗”，均需确认；不操作继续占用，不因已读消失。
2. 未到诊申请通过：原预约取消，关联权益的占用减1，无核销、无费用，首页该待处理提醒消失。重复申请或已核销无法重复恢复；已过期只解除占用，不延期。
3. 已到诊反馈：占用保留，新建门诊待补核销；若门诊此前报未到则异常搁置，不能自行裁决。各组数据独立，客户反馈不自动出现在另一组门诊原型；测试通过显式夹具传递演示同一流程。
4. 门诊工作台→过期预约待办→OD24：可报患者未到（取消但不释放）、协商改期或补核销。门诊不能通过旧“无法接诊”入口直接释放已过时间的成功预约。
5. 门诊OD72为系统自动完成且未核销，点补核销→读取预填凭证`VISIT-OD72`→核对原数量/费用→勾选已完成服务→确认核销；此时消耗1份、记费60元，原任务历史保留。OD24凭证为`VISIT-OD24`。
6. 两端处理页可查看任务编号和过程。门诊待办页提供固定2026-09-07 12:00的模拟定时检查，24/72小时规则无真实计时服务。完成后的错误核销仍走独立撤销流程。
7. 补核销不豁免过期/冻结/改期待确认/冲突/占用不足校验；已恢复后不能继续扫码，核销后不能通过未到申请恢复。日期口径已由REQ-037确认：按最后生效预约日期判断有效期，不按实际补核销日；本段旧演示限制不替代当前规则。
