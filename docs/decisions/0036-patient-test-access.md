# ADR-0036 患者端微信测试访问边界

状态：采用保留现有Basic认证的测试方案，实施中；关联 REQ-058、TASK-117。自动安全审查拒绝了对患者API路由关闭Basic认证的补丁，原因是会扩大公网访问边界；该路由未部署。

用户选择使用现有受保护开发验收库，并授权本人手机测试。该环境含模拟短信和支付，不得向普通微信用户开放注册或解除后台Basic保护。测试版患者小程序由用户在运行时手动输入现有验收入口账号和口令，凭据仅存内存、经HTTPS发送，不编入代码、不持久化、不经过聊天；现有Nginx Basic认证不变。仅特定开发域名、患者端测试构建可启用此模式。后台仍接收正常的会话令牌；请求头区分Basic认证与业务身份。患者手机号经过微信真实授权校验之后，服务端在创建客户或会话之前核对允许范围；每次会话鉴权再次检查。测试号码移除后既有会话也失效。索引沿用现有的加密HMAC手机号索引，私有配置不保存明文测试手机号。

AppSecret和测试手机号仅由用户在本机终端以不回显方式输入，通过现有SSH安全传输至服务器0600权限的暂存文件。暂存步骤不修改运行配置、不开放入口；配置合并和服务重启须先检查当前状态、备份并完成权限验证。真实微信调用受既有限流约束，开发验收环境仅用于受控测试，并存在消耗微信手机号验证额度的可能。

关闭时停用患者验收配置并重启服务，不删除、还原或覆盖验收库内新产生的业务记录。生产不能启用模拟环境或使用该临时测试模式，真实上线须独立评审。真实外部接口、IP白名单、隐私声明和手机验证均须另行核实。
