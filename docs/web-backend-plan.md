## 验收口径

不使用“菜单可打开”替代业务完成。每个写入流程检查成功后的服务端持久化、关联待办、日志及权限拒绝；模拟外发明确标识。测试不得写入用户正在体验的验收业务记录，另建服务器隔离回归环境。独立验收数据库部署前备份，种子命令不重置数据。
