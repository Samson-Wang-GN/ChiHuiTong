# ADR-0002 合作方合同承载权益授权与分配

- 日期：2026-09-07
- 状态：已接受；余额/舍入与核销锁费已由REQ-037确认，存量合同及核销渠道按REQ-042，不再待评审。
- 关联：REQ-020、TASK-021

## 决定与理由

将方案主档与合同条款分离。主档定义服务及单次获客费；合作方合同添加方案并定义该方分配。相比全局统一比例，此结构支持不同合作价格且让授权边界可追溯。门诊沿当前所属渠道继承可用方案，不复制合作方费率，也不能扩大上游授权。

平台提供合同记录的直接入口和可跨合同筛选的配置列表，复用现有 Arco 表格、表单及详情，不引入新组件库或生产技术栈。各组原型数据仍独立；不为演示跨角色同步而共享其他机构的合同数据。

旧浏览器本地数据只迁移业务记录，不采用其旧页面、动作、表单配置。新增默认记录与新页面合并，既有状态及用户新增记录保留；全局方案旧比例字段废止，不自动转为真实合同条款。新合同条款样例均为虚构评审数据。

## 代价与后果

正式实现需要跨资源方/渠道合同组合校验、版本快照、日期生效控制及高风险修改审计。原型使用固定评审日期2026-09-07、静态合同/机构样例，不能替代生产授权。平台取剩余金额、四舍五入至分及核销锁费已确认（REQ-037）；存量合同选择及渠道按核销时归属见REQ-042。
