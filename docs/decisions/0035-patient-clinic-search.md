# ADR-0035 患者端门诊发现与公开区域搜索

状态：实施中。关联 REQ-058、TASK-117。

患者端原门诊发现只查询旧版门诊合同，不能识别新版签约主体合同。选择按同一主体先选择最近一版已经审核且到生效时间的合同，再检查终止、到期、门诊覆盖和产品授权；保留旧合同路径并继续验证渠道合同、机构、门诊及产品状态。不能因选择未来合同或回退旧版而提前放开预约，服务端预约仍重新校验。

既有门诊资料整体加密存储，无法在数据库内按省、市、区搜索。新增仅包含已审核门诊省、市、区的公开区域投影，审核通过时与资料同事务更新；迁移只回填已生效快照，不复制待审资料、详细地址、联系人或患者资料。查询在数据库使用区域投影及机构名称进行匹配，并保留既有分页；不解密和遍历所有患者或门诊资料。此字段不包含凭证，属于原本对可预约患者公开的门诊位置范围；保留原加密资料为事实来源。后续规模增长时按真实查询负载评估索引，不能依赖任意数量上限。

迁移为扩展及回填，原字段不改；回退代码前应确认新旧数据和后续写入，不能用旧数据库备份覆盖新增业务。生产迁移、数据及权限边界须非作者评审；服务器自动化和真实微信验收分别记录。
