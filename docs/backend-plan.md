## 自主决定（供用户审阅）

1. 不改小程序UI，但实现共同后端和客户闭环接口；不同登录端凭证受众隔离，普通客户不能访问门诊后台。
2. 独立PG实例/虚拟环境，不借用公共数据或更改共享服务。
3. 后台使用短期、可撤销不透明会话，服务端仅存摘要；验证码单次、短时、限速及限制失败次数，API/日志不返回验证码。测试注入短信适配器观察合成消息。
4. 当前负责关系只落销售订单/门诊，下游稳定外键解析；历史收益方/操作人不可变，不实现交接。
5. 新业务要求当前有效合同，存量履约回溯已审核生效过的适用版本；缺失明确拒绝，不默认零费用。
6. 预约提醒提供鉴权完整待确认快照及版本，建议前端每5秒轮询、重连重新取快照；只编号/意向时间/版本，不含患者资料。本轮不改浮窗。
7. 审核工作日使用可维护日历，周末为初始默认；节假日/调休需平台录入才承诺精度。付款期限始终自然日。

后续决定和测试结果随实现追加；未实现不得标完成。真实商户/短信/地图/小程序配置缺失仅限制对应真实联调，不取消代码及模拟异常测试。
