甲乙双方本着平等、自愿、诚实信用的原则，就乙方通过齿慧通平台承接口腔福利服务，达成如下协议。

## 第一条 合作内容

1. 甲方运营齿慧通平台，为客户、客户资源方和合作门诊提供福利权益展示、门诊查询、预约信息传递、权益核验、核销记录及相关业务管理服务。
2. 乙方在具备相应执业资质和实际服务能力的范围内，为持有有效权益并完成预约的客户提供相应口腔服务。
3. 本协议仅覆盖列明的合作门店。合作产品名称及单次获客服务费以本协议列明内容为准；具体服务及客户权益规则以相应产品已确认且有效的规则为依据。
4. 甲方可委托渠道合作方或业务人员协助资料收集、送签、入驻和日常沟通。渠道合作方不因协助行为成为本协议签约方，也不因此成为乙方的付款责任主体或担保方。
5. 除双方另有书面约定外，甲方不保证最低预约量、到诊量、核销量、收入或客户转化效果。

## 第二条 合作期限与上线

1. 本协议由双方依法签署后成立，合作期限按本协议列明的起止时间执行。
2. 协议签署后，乙方门店仍须完成资质审核、合同审核、产品授权和上线检查。合同签署本身不等于门店已上线，也不自动赋予承接新预约的权限。
3. 合作期届满前，双方可协商续签。续签应以双方认可的书面文件或其他合法有效方式办理；新文件生效前不当然延长原协议期限。
4. 乙方签约主体与门诊执业主体不一致的，应在签署前提供合法有效的授权及责任承担依据，并经甲方核验；未经双方书面确认，本协议不自动覆盖其他门店。

## 第三条 甲方权利与义务

1. 甲方负责提供本协议项下的平台服务，按约定向乙方展示与其合作范围有关的预约、权益核验和核销信息。
2. 甲方有权对乙方主体、门店资质、合作产品和服务状态进行审核，并对异常预约、核销及付款情况进行核查。
3. 甲方应向乙方说明合作产品和核销付款流程，并在系统发生影响履约的故障时及时处理或通知乙方。
4. 甲方应按法律法规和本协议要求保护其处理的客户及乙方信息，依法处理乙方对平台服务、账务及异常事项提出的反馈。

## 第四条 乙方资质与资料

1. 乙方应具备开展本协议项下口腔诊疗活动所需的有效资质，确保执业地点、诊疗科目、执业人员及诊疗行为符合适用要求。
2. 乙方应提供真实、完整、有效的主体信息、执业资质、门诊地址、联系方式、营业时间及其他必要资料，并对其真实性负责。
3. 资质、执业地点、名称、经营主体、营业状态或联系方式发生变化，可能影响本协议履行的，乙方应及时通知甲方并提供必要证明材料。
4. 涉及平台展示或门诊服务资格的资料变更，按平台资料审核流程处理；法律法规或安全情况要求立即停止展示或服务的除外。
5. 乙方不得将平台账号、预约信息或服务资格提供给未经授权的其他门诊或人员使用。

## 第五条 预约与医疗服务

1. 客户选择权益、门诊和意向时间提交预约。乙方应根据实际接诊能力及时处理，并与客户沟通确认最终预约时间。
2. 乙方无法接诊的，应及时按实际原因处理预约，并按平台流程通知客户或配合甲方通知客户。
3. 乙方应按照客户持有的有效权益及相应产品规则提供服务，服务前清晰告知服务范围、限制条件和客户自费项目。
4. 对权益范围以外的诊疗或收费项目，乙方应事先向客户说明内容、费用及其他必要事项，并依法取得客户同意。客户是否接受其他项目，不影响其依法享有的选择权。
5. 乙方独立负责其诊疗方案、执业行为、医疗质量、医疗安全及工作人员管理；甲方负责其平台服务范围内的义务。一方过错造成损失的，由有过错方依法承担相应责任。
6. 到诊、未到诊、改期、取消和其他履约反馈应按真实情况记录。发生反馈冲突时，乙方应配合核实，不得以虚假信息办理核销。

## 第六条 权益核验与核销

1. 乙方应在服务前通过平台核验预约、客户权益及门诊资格，确认客户已接受约定服务后，按平台流程办理核销。
2. 乙方不得虚构服务、重复核销、超量核销或将权益用于其他客户。客户未到诊、未完成约定服务，或预约、权益不符合核销条件的，不得办理核销。
3. 服务事实或核销记录存在疑问时，双方应保留记录并及时核实。**已完成收款和核销的业务，乙方不得自行撤销、重复核销或擅自改变收款事实**；发生错误时应联系甲方处理。
4. 本条不排除双方依法处理客户投诉、医疗纠纷或款项争议的义务。

## 第七条 获客服务费与支付

1. 乙方就有效核销，按照本协议列明的对应产品单次获客服务费向甲方支付费用，适用本次业务对应的有效约定。
2. **单店采用当次核销现付。**乙方完成约定服务并确认核销信息后发起支付；平台以可信支付结果确认足额收款后完成该次核销。
3. 乙方为付款责任主体，可安排授权员工使用工作手机按平台流程完成支付；实际操作员工不因此成为合同付款责任主体。
4. 平台在支付前展示本次产品、核销数量和应付金额。乙方发现有误的，应在付款前停止操作并联系甲方核实。
5. 支付结果不明确时，双方应先核实原订单状态，不以截图、口头说明或页面暂未更新作为唯一到账依据。已确认收款但核销尚未完成的，甲方应保留收款记录并组织核查、恢复；乙方无需就同一笔已确认收款重复支付。
6. 合作产品约定的获客服务费为零时，按平台核验流程办理，无需发起零元支付。
7. 对重复付款、超额付款、错误核销及其他款项异常，双方应及时核对事实和支付记录并依法协商处理；本条不表示平台已具备自动退款功能。

## 第八条 产品和费用变更

1. 新增、停止或调整合作产品、服务内容或获客服务费，应由双方通过书面补充协议或双方认可的其他合法有效方式确认，并明确生效时间。
2. 已完成核销的历史费用以该次交易适用的有效合同及费用记录为依据；后续调整不当然追溯改变既有交易。
3. 产品调整可能影响已预约服务时，双方应及时沟通处理，依法保护客户权益；具体计费适用以有效合同和平台规则为准。

## 第九条 个人信息与保密

1. 双方应在各自职责范围内依法处理履约所需的客户信息，仅用于完成预约、履约、核验、客户服务和争议处理等必要事项。
2. 双方应根据实际业务明确各自的个人信息处理角色、目的、范围、保存期限、访问权限及告知安排。涉及委托处理、共同处理、向第三方提供或敏感个人信息处理的，应依法具备相应基础并落实必要保护措施；必要时另签个人信息处理协议。
3. 乙方应限制有权访问平台信息的人员范围，不得将客户信息用于与本协议无关的营销、转售、共享或其他用途，法律法规允许且已满足相应条件的除外。
4. 乙方负责保管账号及身份验证信息；发现账号被盗用、数据泄露或其他安全事件时，应及时采取控制措施并通知甲方，双方依法配合处置。
5. 双方对合作中获知的未公开商业信息承担保密义务；法律法规要求披露、监管机关依法要求提供或经信息提供方事先同意的除外。合作终止后依法应当保留的记录不因终止而擅自删除。

## 第十条 暂停、终止与存量预约

1. 乙方可根据实际经营情况申请暂停合作或停止承接新预约，并与甲方确认生效时间及尚未完成事项。
2. 乙方资质失效、无法正常接诊、涉嫌虚假核销、严重影响客户权益或存在其他可能导致合作无法安全履行的情况时，甲方可根据实际情况暂停展示或新预约并及时通知乙方；法律法规另有规定或紧急情况需要先行处置的除外。
3. 合同到期、暂停或终止时，双方应核对未完成的预约、权益、支付和投诉事项。对已确认的存量预约，乙方具备继续履约条件的，应与甲方协商妥善完成；确实无法履约的，应及时通知客户并按实际原因逐条处理。
4. 暂停或终止不自动视为双方已完成结算，也不消除终止前已发生的权利义务。保密、个人信息保护和争议处理条款按其性质及法律规定继续适用。

## 第十一条 违约责任

1. 任何一方违反本协议给另一方造成损失的，应依法承担相应责任。
2. 一方发现另一方违约的，可要求其在合理期限内说明情况并采取补救措施；因违约性质、紧急情况或法律规定不适宜补救的除外。
3. 一方因客户投诉、行政调查或争议处理需要另一方提供合作记录的，另一方应在合法、必要及其权限范围内配合。
4. 因虚假核销、虚假资料、超出执业范围提供服务或平台服务过错等引发争议的，双方应先核实事实，按各自过错及依法应承担的责任处理。

## 第十二条 通知与争议解决

1. 双方应保持合作联系信息有效；信息发生变化时应及时通知对方，并按平台流程更新。
2. 因本协议产生的争议，双方应先协商解决；协商不成的，任何一方可依法向有管辖权的人民法院提起诉讼。

## 第十三条 其他

1. 双方确认的补充协议及其他明确列为本协议组成部分的文件，与本协议具有同等效力。
2. 本协议未尽事宜，由双方协商并以书面形式补充；补充文件与本协议不一致的，以双方明确约定的适用顺序为准。
3. 本协议一式两份，甲乙双方各执一份，具有同等法律效力。
