# ADR-0034 合同正文的有限 Markdown

状态：实施及验证中。关联 REQ-052、TASK-111。

合同正文需呈现标题、强调和列表。备选是继续纯文本、引入完整 Markdown/HTML 渲染器或实现限定语法；选择限定语法，避免扩展外部资源、脚本和复杂 HTML 的攻击面，也不增加依赖。模板记录格式，新版 Markdown 在解析结构之后插入按普通文字转义的字段；纯文本及历史快照保持旧行为。中文加粗使用 PDF 填充和轻描边，依赖现有中文字体，实际打印效果须服务器验证。未知语法保留字面，表格和强制分页不在范围内。取消此方案可停止发布 Markdown 模板，但已有版本必须继续支持或先迁移并验证，不修改已签文件。
