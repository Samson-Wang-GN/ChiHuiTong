# ADR-0025：事件指标、合同配置校验与地址定位边界

状态：实施中，待远程综合验证。日期：2026-09-12。

## 决定

- 客户权益概览仅平台及客户资源方开放。按开卡审批日期确定批次集合，以不可变DomainEvent还原观察时点，而不是用当前预约/核销状态覆盖历史。事件同时保留发生与记录时间；查询返回二者截止参数，图表、明细、导出复用。账户及机构权限始终重新校验。
- 当前客户标签属于最新授权资料，历史趋势不补造历史姓名。记名客户开卡后纳入人数，不记名仅激活后绑定；系统自动完成无核销事件，故不产生核销数。人员按稳定ID去重；百分比用原始分子/分母、一位小数四舍五入；零分母返回空。
- 默认近30天批次；趋势单次不超过366点，需长跨度时选择周/月或分段。这是资源保护，不限制客户/机构总量。首次版本采用数据库索引查询，不引入第二套分析数据库；后续压测如需聚合，可复用相同事件与口径。
- 合同产品配置、合同审核激活和获客费修改均检查当前适用及已审核未来分配组合。忽略已被替代的历史条款；停用条款仍可能用于存量履约，不当作零分配。计算和核销串行化于推广产品锁；历史核销快照不追溯改写。
- 机构的合同与可用产品通过合作信息汇总接口展示，同一管理页可以查询当前合同、下一份待生效合同、待审核合同及产品入口。合同列表区分待生效、生效、到期、被替代等状态；没有创建第二份独立机构合同。

## 地址定位

选腾讯位置服务WebService地址解析，接口仅接收门诊省市区和详细经营地址，不外发患者资料。原因：项目已有GCJ-02坐标基线，后续地图和小程序可沿用，避免混合坐标系。

[官方地址解析说明](https://lbs.qq.com/service/webService/webServiceGuide/address/Geocoder)确认返回GCJ-02、reliability及level；可靠度不足7、精度低于门址级别9时重点提示人工调整。无论评分如何均要求在地图确认，服务端不会把自动候选直接写为已审核门诊坐标。地址改变后原确认无效，修改仍走门诊资料审核并保留旧生效资料。

2026-09-12网页检索器打不开该官方页面，通过公开HTTPS直接读取官方文档正文核对。适配代码固定HTTPS域名，不接受用户提供URL，不跟随重定向，不输出密钥、原始远端错误或查询URL。配置缺失明确503；保留人工地图选点流程。本轮不改小程序及地图前端，不声称真实定位联调已完成。

## 短信重试证据

每次实际发送尝试单独记录使用的模板版本和无客户数据的模板配置快照；修改报备模板后重试使用新配置并保留旧尝试。发送号码与参数保留在加密的发送记录中，平台列表只展示脱敏号码，失败记录不泄露报文。服务商接受仍不等于手机已送达。

## 代价和后续

按事件回放比读当前状态开销更高，需在指定开发服务器继续做容量验证。地图Key、微信主体/AppID/商户号、短信报备仍需真实配置后联调；不能用模拟结果替代。此次没有修改共享服务器公网端口或共享服务。
