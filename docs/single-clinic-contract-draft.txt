甲乙双方本着平等、自愿、诚实信用的原则，就乙方通过齿慧通平台承接口腔福利服务，达成如下协议。

第一条 合作内容
1. 甲方运营齿慧通平台，为客户、客户资源方和合作门诊提供福利权益展示、门诊查询、预约信息传递、权益核验、核销记录及相关业务管理服务。
2. 乙方在具备相应执业资质和实际服务能力的范围内，为持有有效权益并完成预约的客户提供约定的口腔服务。
3. 合作产品及单次获客服务费以本协议首页列明的内容为准；具体服务项目、服务内容、适用条件及单次核销数量以双方确认的附件一为准。
4. 甲方可委托渠道合作方或业务人员协助乙方办理资料收集、合同送签、入驻和日常沟通。渠道合作方不因上述协助成为本协议签约方或乙方付款责任主体。
5. 甲方不保证最低预约量、到诊量、核销量、收入或客户转化效果；双方另有书面约定的除外。

第二条 合作期限与生效
1. 本协议自双方有权签署人签字或盖章之日起成立，合作时间自{{starts_at}}至{{ends_at}}。
2. 签署后，乙方门店仍须完成资质审核、合同审核、产品授权和上线检查。合同签署不等于门店已上线，也不自动赋予承接新预约的权限。
3. 合作期届满前，双方可协商续签。续签应以双方认可的书面文件或其他合法有效方式办理；新文件生效前不当然延长原合同期限。
4. 本协议仅覆盖所列门店。乙方签约主体与门诊执业主体不一致的，应在签署前提供合法有效的授权及责任承担依据并经甲方核验；未经双方书面确认，不自动覆盖其他门店。

第三条 门诊资质与资料
1. 乙方应具备开展本协议项下口腔诊疗活动所需的有效资质，确保执业地点、诊疗科目、执业人员和诊疗行为符合适用要求。
2. 乙方应提供真实、完整、有效的主体信息、执业资质、门诊地址、联系方式、营业时间及其他必要资料，并对资料真实性负责。
3. 资质、执业地点、名称、经营主体、营业状态或联系方式发生变化，可能影响协议履行的，乙方应及时通知甲方并提交证明材料。
4. 涉及平台展示或门诊服务资格的资料变更，经平台审核生效前原则上继续展示原有效资料；法律法规或实际安全情况要求立即停止展示或服务的除外。
5. 乙方不得将平台账号、预约信息或服务资格提供给未经授权的其他门诊使用。

第四条 预约与服务履行
1. 客户选择权益、门诊和意向时间提交预约。乙方应根据实际接诊能力及时处理预约，与客户沟通后确认最终预约时间。
2. 乙方无法接诊的，应及时在平台按实际原因处理，并按平台流程通知客户或配合甲方通知客户。
3. 乙方应按照附件一及客户实际持有权益提供约定服务，服务前清晰告知权益范围、限制条件和客户自费项目。
4. 对权益范围以外的诊疗或收费项目，乙方应事先向客户说明内容、费用及其他必要事项，并依法取得客户同意。客户是否接受其他项目，不影响其依法享有的选择权。
5. 乙方独立负责诊疗方案、执业行为、医疗质量、医疗安全及工作人员管理；甲方负责其平台服务范围内的义务。一方过错造成损失的，由有过错方依法承担相应责任。
6. 到诊、未到诊、改期、取消、补核销及权益恢复应按真实情况记录。发生反馈冲突时，乙方应配合核实，不得以虚假信息办理核销。

第五条 权益核验与核销
1. 乙方应在服务前通过平台核验预约、客户权益及门诊资格；确认客户已接受约定服务后，按平台流程办理核销。
2. 核销数量以客户权益、预约及附件一允许的数量为准。乙方不得虚构服务、重复核销、超量核销或将权益用于其他客户。
3. 客户未到诊、未完成约定服务，或预约、权益不符合核销条件的，不得办理核销。
4. 服务事实或核销记录存在疑问时，双方应保留相关记录并及时核实。已完成收款和核销的业务，乙方不得自行撤销、重复核销或擅自改变收款事实；发生错误时，双方应联系并按另行确认的异常处理流程办理。
5. 本条不排除双方依法处理客户投诉、医疗纠纷或款项争议的义务。

第六条 获客服务费与支付
1. 乙方就有效核销，按照本协议首页及附件一列明的金额和计费单位向甲方支付获客服务费，适用有效合同版本。
2. 乙方为付款责任主体，可安排授权员工使用工作手机按平台流程完成支付；实际操作员工不因此成为合同付款责任主体。
3. 单店采用当次核销现付。乙方完成约定服务并确认核销信息后发起支付；平台以可信支付结果确认足额收款后完成该次核销。
4. 平台在支付前展示本次产品、核销数量和应付金额。乙方发现有误，应在付款前停止操作并联系甲方核实。
5. 支付结果不明确时，双方应先核实原订单状态，不以截图、口头说明或页面暂未更新作为唯一到账依据。已确认收款但核销尚未完成的，甲方应保留收款记录并组织核查、恢复，乙方无需就同一笔已确认收款重复支付。
6. 约定的获客服务费为零时，按平台核验流程办理，无需发起零元支付。
7. 实际收款主体、支付渠道、手续费承担、收款主体与甲方的关系及必要授权，以附件二约定为准。涉及发票的开票主体、发票类型、开票周期和申请方式，以附件二约定为准。
8. 对重复付款、超额付款、错误核销及其他款项异常，双方应及时核对事实和支付记录，依法协商处理。退款条件、办理时限和路径以附件二或双方另行签署的补充协议为准；本条不表示平台已具备自动退款功能。

第七条 产品及费用调整
1. 新增、停止或调整合作产品、服务内容、单次核销数量或获客服务费，应由双方通过书面补充协议或双方认可的其他合法有效方式确认，并明确生效时间。
2. 已完成核销的历史费用以该次交易适用的有效合同及费用记录为依据；后续调整不当然追溯改变既有交易。
3. 产品调整可能影响已预约服务时，双方应及时沟通处理，依法保护客户权益；具体计费适用以有效合同和平台规则为准。

第八条 个人信息与保密
1. 双方应在各自职责范围内依法处理客户姓名、联系方式、预约及权益信息，仅用于完成预约、履约、核验、客户服务和争议处理等必要事项。
2. 双方应根据实际业务明确各自的个人信息处理角色、目的、范围、保存期限、访问权限及告知安排。涉及委托处理、共同处理、向第三方提供或敏感个人信息处理的，应具备相应合法基础并完成必要告知、同意及专项评估；必要时另签个人信息处理协议。
3. 乙方应限制有权访问平台信息的人员范围，不得将客户信息用于与本协议无关的营销、转售、共享或其他用途，法律法规允许且已满足相应条件的除外。
4. 乙方负责保管账号及身份验证信息；发现账号被盗用、数据泄露或其他安全事件时，应及时采取控制措施并通知甲方，双方依法配合处置。
5. 双方对合作中获知的未公开商业信息承担保密义务；法律法规要求披露、监管机关依法要求提供或经信息提供方事先同意的除外。
6. 合作终止后，双方依照法律法规及约定处理各自保存的信息；依法应当保留的记录不因合作终止而擅自删除。

第九条 暂停、终止与存量预约
1. 乙方可根据实际经营情况申请暂停合作或停止承接新预约，并与甲方确认生效时间及尚未完成事项。
2. 乙方资质失效、无法正常接诊、涉嫌虚假核销、严重影响客户权益或存在其他可能导致合作无法安全履行的情况时，甲方可根据实际情况暂停展示或新预约并及时通知乙方；法律法规另有规定或紧急情况需要先行处置的除外。
3. 合同到期、暂停或终止时，双方应核对未完成的预约、权益、支付和投诉事项。对已确认的存量预约，乙方具备继续履约条件的，应与甲方协商妥善完成；确实无法履约的，应及时通知客户并按实际原因逐条处理。
4. 终止不影响终止前已发生款项的核对、依法应承担的责任，以及依其性质应继续有效的保密、个人信息保护和争议解决条款。暂停或终止不自动视为双方已完成结算，也不自动消除已发生的权利义务。

第十条 违约责任
1. 任何一方违反本协议给另一方造成损失的，应依法承担相应责任。
2. 一方发现另一方违约的，可要求其在合理期限内说明情况并采取补救措施；因违约性质、紧急情况或法律规定不适宜补救的除外。
3. 一方因第三方投诉、行政调查或争议处理需要另一方提供合作记录的，另一方应在合法、必要及其权限范围内配合。
4. 因乙方虚假核销、虚假资料或超出执业范围提供服务等行为引发争议的，双方应先核实事实，按各自过错及依法应承担的责任处理。

第十二条 争议解决
本协议适用中华人民共和国法律。因本协议产生的争议，双方应先协商解决；协商不成的，按附件二中双方选定的争议解决方式处理。

第十三条 其他

2. 本协议未尽事宜，由双方协商并以书面形式补充；补充文件与本协议不一致的，以双方明确约定的适用顺序为准。
3. 本协议一式两份，甲乙双方各执一份，具有同等法律效力。
