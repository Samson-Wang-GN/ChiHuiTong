# ADR-0003 单主合同与渠道合同分列表

- 日期：2026-09-07
- 关联：REQ-022、TASK-023
- 状态：已接受；续签版本流程沿用既有要求，本轮不新增审批实现

> 2026-09-08：本文渠道双列表及双边门诊合同部分已由[ADR-0005](0005-periodic-billing-tripartite-contracts.md)替代；下文保留历史决策和原型实现事实。资源方单主合同、多方案及历史保留原则继续有效。

每个资源方与平台是一份主合同、多方案条款，不能按方案另建主合同。历史续签及变更仍须保留版本，不能以“只有一份”作为覆盖历史的理由。正式实现需以资源方机构键保证主合同唯一性，原型先在登记时阻断重复。

渠道后台保留原contracts路由作为“与平台合作合同”，增加clinicContracts路由作为“平台与门诊合同”。分别配置固定合同类型，查询、状态计数与导出统一应用该范围。两页各自使用状态Tab，不增加新的审批权限。渠道合同方案授权仍引用原合同ID，不随页面拆分改变。

旧本地混合列表记录保持原合同ID、主体、类型及用户修改；首次创建新门诊列表时从旧缓存映射平台—门诊行。旧渠道—门诊资料留在原缓存，不混入两个指定列表、不改签约方。此为原型兼容处理，不代表生产迁移或权限已经实现。
